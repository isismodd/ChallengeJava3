# ClyvoPet

Sistema web para gerenciamento de uma clínica veterinária, desenvolvido
em Java com Spring Boot.

O ClyvoPet permite o gerenciamento de veterinários, animais, consultas
e lembretes, contando com autenticação e autorização por perfil,
persistência em banco de dados Oracle e envio de notificações por e-mail.
